# Session record sheet
## One sheet per participant. Print five.

```
Participant: P___          Session length: _____ minutes
Facilitator: ______________  Note taker (if two of you): ______________
Program version / commit: ______________________

Consent line read as written?      [ ] yes
Answered yes out loud?             [ ] yes
Anything recorded?                 [ ] no      <- this must be no
Any name written anywhere?         [ ] no      <- this must be no
```

## Per task, the three numbers

```
        completed?   time on task   attempts   first place they looked
Task 1  ___________  ____________   ________   _______________________
Task 2  ___________  ____________   ________   _______________________
Task 3  ___________  ____________   ________   _______________________
Task 4  ___________  ____________   ________   _______________________
```

**Completed means they got the answer**, not that they were satisfied.

**Attempts means separate tries before something worked**, including the ones that
produced an error.

## Things you may not say, for your own reference

```
1  the name of a control      2  "you can"

```

## Did you break a rule?

Be honest. It is more useful than a clean sheet.

```
[ ] I helped when I should not have. What I said: _____________________
[ ] I asked "did that work?"
[ ] I made a face
[ ] I did not break any of them
```

**A session where you slipped is still usable.** Note which task it happened on,
so that the finding from that task carries the caveat.

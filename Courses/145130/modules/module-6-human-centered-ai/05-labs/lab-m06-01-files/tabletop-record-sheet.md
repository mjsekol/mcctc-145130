## If the table is empty

**A tabletop that found nothing was run by somebody being polite, or by somebody
describing instead of doing.**

Run it again, with a different partner, with the rule said out loud first. If you
have less than twenty minutes left, run the two tasks you are least sure about
properly rather than all four badly.

# Lab M06-02 files · the Bellfield Note Sorter study

**Everything in this folder is invented.** The program, the participants, the
sessions, and the summary were all written for this lab. **The five session records
are internally consistent with each other and with the program description**, which
means every claim in the summary can be checked against them and the answer is
always in the files.

**No real person appears anywhere in this folder.** Participants are P1 through P5,
which is the same rule your own study runs under.

| File | What it is |
|---|---|
| `program-description.md` | What the Bellfield Note Sorter does, and what its digest looks like |
| `session-P1.md` to `session-P5.md` | Five session records, two columns, numbered lines |
| `submitted-summary.md` | A report somebody wrote from those five sessions |
|  `severity-table-template.md` | The blank table you fill in |

**Read `program-description.md` first.** Several claims in the summary are about
what the program does, and you cannot judge those without it.

**Lines are numbered `L1`, `L2` and so on.** Your findings cite them as `P3 L7`. A
finding with no citation is not a finding.

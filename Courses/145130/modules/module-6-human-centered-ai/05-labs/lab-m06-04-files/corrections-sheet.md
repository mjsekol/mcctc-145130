## Anything deferred

**A case you are not going to fix this week is a complete outcome as long as it is
written down.** What it needs:

```
Case:              ______________________________________________________

Why we are not fixing it: _______________________________________________
                   ______________________________________________________

What we agreed with the stakeholder: ____________________________________
                   ______________________________________________________

Who would own it:  ______________________________________________________

Would it be first if this continued? [ ] yes  [ ] no
```

**A known failure recorded honestly is a full-marks deliverable.** A known failure
recorded as a pass is the one thing that is not, because the next person builds on
it.

---

## The re-run rule

**Re-run the whole procedure, not only the case you fixed.**

A change that fixes AC-4 and breaks AC-1 is ordinary, and you will not find it by
re-running AC-4. Eight cases takes ten minutes by hand and less than a minute if
you wrote a program for it.

```
[ ] Full procedure re-run after the last correction
[ ] Final counts:  PASS ______  FAIL ______  NOT RUN ______
```

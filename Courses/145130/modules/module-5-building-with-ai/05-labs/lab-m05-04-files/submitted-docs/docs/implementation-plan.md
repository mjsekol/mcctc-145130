# Implementation Plan

## What has to be true before you start

Python and .NET must be installed. The repository must be cloned. The model must
be downloaded and running on the machine before any development begins, because
nothing can be tested without it.

## Milestones

1. Design complete
2. Service complete
3. Client complete
4. TODO: add testing milestone

## Who does what

The team divides the work between the frontend and the backend. Each member is
responsible for their own area and for reviewing the other's code before it is
merged into the main branch.

## How you know each milestone is finished

Each milestone is finished when the code for it is written and committed to the
repository, and the developer is satisfied that it works as intended on their
machine.

> We are going to run eight checks we agreed on Thursday. Some of them are meant to
> fail, because they are checking that the program notices when something is wrong.

## The three rules, and tick them honestly

```
[ ] We did not change a case because it was about to fail
[ ] Every FAIL is written down, including the ones that were embarrassing
[ ] Every NOT RUN has a reason next to it
```

**Between one and four failures is normal.** Eight passes on a first run usually
means the cases were written to pass, and your instructor will ask which case could
have failed.

# Icon set: Study 24

Sixteen icons used on the printable card sheet. The real download is a set of
SVG files. This file stands in for them so the fixture carries no binaries.

| File | Used on |
|---|---|
| `book.svg` | Deck header |
| `timer.svg` | Drill screen |
| `check.svg` | Correct answer |
| `retry.svg` | Wrong answer |

The Study Buddy team recolored `check.svg` and `retry.svg` to match the school
colors before putting them on the sheet.

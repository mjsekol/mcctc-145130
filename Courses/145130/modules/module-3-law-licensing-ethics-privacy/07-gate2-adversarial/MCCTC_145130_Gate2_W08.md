## What you are scoring

The five AI Output Evaluation parameters, Ohio competency 2.14.4.

| Parameter | The question it asks |
|---|---|
| **Validity** | Is it correct? A false claim about something that exists. |
| **Relevance** | Does it answer what was asked, or something else? |
| **Authenticity** | Is it original, or does it belong to somebody? |
| **Potential Bias** | Whose perspective is built in, and what does it consistently favour? |
| **Hallucinations** | Does it confidently describe something that does not exist? |

**There are six planted problems.** One is in each of those five categories, and a sixth is a
recommendation that is **genuinely arguable**. Finding four is a passing score. Finding six,
correctly categorized, is a strong one.

## What to submit

`gate2-w08.md` in your repository. For each finding:

1. **The exact claim, quoted**, with the section number
2. **Which parameter it fails.** One label per finding
3. **Why it is wrong**, in your own words
4. **How you know.** A primary source you opened and what it said, a file you read, or
   **"I could not verify this, and here is what I did to try"**, which is a complete answer
5. **Who is harmed** if the board acts on this claim. Name them

Then three more sections:

**The arguable one.** One of the six is a recommendation reasonable people disagree about. Name
which, state the strongest case for it, state the strongest case against it, and say what the
answer depends on. **You are not asked to decide it.**

**The arithmetic.** The lecture notes contain the raw scores. The briefing reports one ranking.
Work out what the ranking looks like two other ways and say which of the three, if any, the board
should be given.

**What the board asked for and did not get.** Go through the specification clause by clause.

## Before you start

Three habits, in order of speed:

- **When a number appears, ask what it is a percentage of.** You did this on Wednesday.
- **When a source is named, go to the source.** Not to a page about it. The publisher's own site.
  If the organization does not appear to exist, **record the search that came back empty**. That
  record is the finding.
- **When a document recommends something, ask what the alternatives were.** A briefing that names
  one alternative, and names it as doing nothing, has not compared anything.
